# Contributing to CL40 World & WR Beats Corporate Ecosystem

## Contribution Workflow

1. **Fork & Branch:** Fork the repository and create a dedicated feature branch (`git checkout -b division/feature-name`).
2. **Division Tagging:** Reference the exact entity number and name (01–20) in your commit messages and pull request titles.
3. **Standards & Verification:** Ensure all code, ISRC/ISWC metadata, and documentation are clean, valid, and free of placeholder text.
4. **Pull Request Review:** Submit your pull request to the `main` branch for executive review by the **CL40 World Department** and **CL40 World Labs**.
